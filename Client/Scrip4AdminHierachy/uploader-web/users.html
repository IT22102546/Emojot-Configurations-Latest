Bulk Comm-Center User Upload

Add users to Comm-Center from Excel and put them in lists. Existing users are never created twice or changed.

1. Company: enter the Company ID and token, then load the company. Its lists and profile data fields (e.g. uuid) are read.
2. Template: choose the columns and download the Excel file. One person per row.
3. Upload: the file is checked: Name and Email required, valid emails, no duplicate emails, phone numbers in international format (+94771234567).
4. Send: pick the list(s), run a dry run to see who already exists, then upload. People who already exist (same email) are not created again and their details are not changed; they are still added to the selected lists.
Token: portal → DevTools → Network → any API call → authorization header.
