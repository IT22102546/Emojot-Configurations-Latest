Bulk Admin Hierarchy Upload

Upload ticket categories and their assignees from Excel into a workflow's admin hierarchy

1. Workflow: export the workflow JSON from the portal and upload it. Enter its Workflow ID and Company ID. The Admin Hierarchy ID is read from the JSON.
2. Template: pick the categories/branches (or any ticket fields) and roles you need, download the Excel file and fill in the admins. In a role cell, separate several emails with ;. Clearing a field leaves that column empty for you to fill.
3. Upload: upload the filled Excel. It is checked against the workflow: names must match exactly, no empty cells, valid emails, no duplicate rows.
4. Send: paste the token (portal → DevTools → Network → any API call → authorization header). Run a dry run first, then upload.
Safety: before writing, the tool reads the live hierarchy and sends nothing if a row's _id belongs to another hierarchy or a row would be duplicated. After a fully successful upload everything resets to step 1.
