What do you want to do?

Upload ticket categories and assignees from Excel into a workflow's admin hierarchy, and create Comm-Center users and add them to lists. Both tools work for any company, run in your browser with your own Emojot token, store nothing, and let you check everything with a dry run first.

👥

Comm-Center User Upload

Add people to Comm-Center from Excel and put them in lists.

  • Name, Email, Telephone and profile data fields
  • Existing users are not created twice or changed
  • Adds everyone to the list(s) you pick

Admin Hierarchy Upload

Set who gets assigned and alerted for each ticket category and branch in a workflow.
